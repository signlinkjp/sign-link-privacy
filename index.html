Sign Link
プライバシーポリシー

制定日：2026年8月4日
最終更新日：2026年9月12日

Sign Link（以下「本アプリ」）は、利用者のプライバシーを尊重し、 本アプリで取り扱う情報、その利用目的、保存方法、外部サービスとの関係および 利用者の選択肢について、以下のとおり定めます。 本ポリシーは Sign Link 1.0 の現在の実装を前提としています。

1. 本アプリが取り扱う情報

カメラ映像・画像

手話認識その他のカメラを使用する機能を提供するため、 利用者が許可した場合に限りカメラへアクセスします。 現在の iOS アプリでは、カメラ映像・画像を Sign Link のバックエンドへ保存する設計ではありません。

マイク・音声認識

音声を文字に変換する機能を提供するため、利用者が許可した場合に限りマイクおよび iOS の音声認識機能を使用します。Sign Link は、生のマイク音声を Sign Link のバックエンドへ保存しません。 音声認識の処理方法は、端末、OS、言語、利用可能な認識方式および設定により異なり、 Apple のシステムサービスにより処理される場合があります。

端末内に保存される情報

翻訳履歴、お気に入り、定型フレーズ、表示言語その他の設定などは、 原則として利用者の端末内に保存されます。 設定画面の「データとプライバシー」から、履歴・お気に入り・ローカルデータを削除できます。

Sign Link ID・匿名アカウント

Sign Link ID チャット等のオンライン機能を提供するため、 必要に応じて匿名のバックエンドアカウントを作成し、 バックエンド上のユーザーID、Sign Link ID、表示名、 ID変更に関する状態等を処理・保存します。 本アプリの通常利用に氏名、メールアドレスまたは電話番号によるログインは必要ありません。

Sign Link 内の連絡先

利用者が Sign Link ID を使って相手を登録した場合、 登録関係、相手の Sign Link ID、利用者が設定したニックネーム、 ブロック状態、相手ごとの通知設定等を、連絡先・チャット機能の提供のために処理・保存します。 これは端末のアドレス帳をアップロードする機能ではありません。

Sign Link ID チャット

Sign Link ID チャットでは、送受信したテキストメッセージ、 送信者・受信者を識別するID、送信日時、既読・閲覧状態、 チャット表示に必要な状態等をバックエンドで処理・保存します。 チャット履歴を提供するため、メッセージはサーバー側に保存されます。

QRチャット

QRチャットでは、一時的な接続用識別子、ルーム状態、在室状態、 送信時刻等を通信成立のために処理します。 QRチャットのメッセージ本文はリアルタイム中継され、Sign Link のデータベースへ チャット履歴として保存しない設計です。 不正利用防止のレート制限では、ハッシュ化した一時キー、回数および有効期限を使用します。 ホスティング事業者等が、サービス運用上の技術的なリクエスト情報を 自らのポリシーに基づき処理する場合があります。

通知に関する情報

プッシュ通知を提供するため、APNs のプッシュ通知トークン、 プラットフォーム、登録状態・更新時刻等をバックエンドで処理・保存し、 対象となる匿名ユーザーIDと関連付けます。 通知の配信には Apple Push Notification service（APNs）を使用します。

通報・安全機能

迷惑行為等の通報機能を利用した場合、通報理由、利用者が任意で入力した補足内容、 通報者・対象者を識別するためのID、処理状態等を、 不正利用防止および安全なサービス運営のために処理する場合があります。

2. App Store のプライバシー表示との対応

現在の iOS 版では、主に次のデータタイプをアプリの機能提供のために扱います。

  • ユーザID：匿名バックエンドID、Sign Link ID 等
  • デバイスID：プッシュ通知トークン等のアプリ・端末レベルの識別情報
  • 連絡先：Sign Link 内の連絡先関係・ソーシャルグラフ
  • メールまたはテキストメッセージ：Sign Link ID チャット等のメッセージ
  • その他のユーザーコンテンツ：通報の補足内容等、利用者が生成したその他の内容
  • その他の使用状況データ：既読・閲覧状態、オンライン機能の利用状態等

現在、本アプリはこれらの情報を広告目的のトラッキングに使用しません。 また、利用者の情報を販売しません。

3. 利用目的

  • 文字入力、音声認識、翻訳、読み上げ、手話認識および会話支援機能の提供
  • Sign Link ID、連絡先、チャット、既読・閲覧状態、ブロック・通報機能の提供
  • QRチャットによる一時的なメッセージ通信
  • プッシュ通知の登録・配信および通知設定の反映
  • 不正利用の防止、セキュリティ確保、障害調査およびサービスの安定運用
  • 利用者からのお問い合わせへの対応

4. 端末の権限

本アプリは、利用する機能に応じて次の権限を求める場合があります。

  • カメラ
  • マイク
  • 音声認識
  • 通知

利用者は iPhone の設定から権限を変更できます。 権限を許可しない場合、該当する機能は利用できない、または一部制限されます。

5. 外部サービス・業務委託

本アプリは、認証、データベース、リアルタイム通信、ホスティング、 プッシュ通知その他のアプリ機能を提供するため、外部のインフラサービスを利用します。 これらの事業者には、サービス提供に必要な範囲で情報が処理される場合があります。

音声認識には Apple のシステムサービスが利用される場合があり、 プッシュ通知の配信には APNs を利用します。 外部サービスにおける情報の取り扱いは、各サービス提供者の規約および プライバシーポリシーにも従います。

6. 広告・追跡・分析

現在、本アプリは第三者広告を表示せず、広告目的の追跡を行いません。 また、利用者を特定する目的の第三者分析サービスは使用していません。 将来これらを導入する場合は、本ポリシーおよび App Store 上のプライバシー情報を更新します。

7. 保存期間と削除

端末内に保存された情報は、利用者が本アプリ内の削除機能を使用する、 または本アプリを削除するまで保存される場合があります。

Sign Link ID のアカウント削除機能を実行すると、 プロフィール、連絡先、チャットメッセージ、通知設定、プッシュ通知トークン等、 アカウントに紐づくサーバーデータを削除する処理を行います。 安全運用のための通報記録については、個人を直接識別する情報を削除・匿名化したうえで、 必要最小限の記録を一定期間保持する場合があります。

チャット画面上の履歴をクリアまたは非表示にしても、 相手側の表示やオンライン機能の提供に必要なサーバー上の記録が 直ちに削除されない場合があります。

8. 安全管理

本アプリは、取り扱う情報への不正アクセス、漏えい、改ざん、紛失等を防止するため、 合理的な安全管理措置を講じます。ただし、インターネット通信または電子的な保存方法について、 完全な安全性を保証するものではありません。

9. 未成年者の利用

未成年者が本アプリを利用する場合は、必要に応じて保護者の同意または監督のもとで利用してください。 本アプリは、児童から個人情報を故意に収集すること自体を目的としたサービスではありません。

10. 国外での処理

バックエンド、ホスティング、通知その他の外部サービスを利用する過程で、 情報が利用者の居住国以外に所在するサーバーで処理される場合があります。

11. 重要な場面での利用

音声認識、翻訳、手話認識その他の支援機能の結果には誤りが含まれる場合があります。 医療、行政、契約、緊急時など重要な場面では、必要に応じて対面、書面、 公的な連絡手段その他の確認方法を併用してください。

12. 本ポリシーの変更

本アプリの機能変更、法令改正その他必要に応じて、本ポリシーを変更する場合があります。 重要な変更がある場合は、本ページまたは本アプリ内でお知らせします。 変更後のポリシーは、本ページに掲載した時点から適用されます。
